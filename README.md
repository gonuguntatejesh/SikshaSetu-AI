# 🌉 SikshaSetu AI (शिक्षासेतु - ᱥᱤᱠᱷᱟᱹ ᱥᱮᱛᱩ)

> **Mother-Tongue Learning Assistant for Primary School Children**  
> Bridging Hindi classroom instructions and Santhali (Ol Chiki) mother-tongue understanding.

---

## 📖 परियोजना का परिचय (Project Overview)
**SikshaSetu AI** एक AI-सक्षम मातृभाषा शिक्षण सेतु है, जिसे विशेष रूप से उन प्राथमिक विद्यालयों के लिए बनाया गया है जहाँ शिक्षक कक्षा में **हिंदी** में पढ़ाते हैं, जबकि जनजातीय बच्चे घर में अपनी मातृभाषा **संथाली (Santali)** बोलते हैं।

यह एप्लिकेशन राष्ट्रीय शिक्षा नीति (**NEP 2020**) के मातृभाषा-आधारित प्राथमिक शिक्षण के संकल्प को धरातल पर उतारने में मदद करता है।

---

## 🌟 मुख्य विशेषताएँ (Key Features)

1. **कक्षा संवाद अनुवादक (Classroom Translator):**
   - शिक्षक सामान्य हिंदी निर्देश (उदा. *"बैठ जाओ"*, *"किताब खोलो"*, *"पानी पीना है?"*) बोल या लिख सकते हैं।
   - संथाली लिपि **ओल चिकी (Ol Chiki)**, रोमन उच्चारण और देवनागरी मार्गदर्शिका में तुरंत रूपांतरण।
2. **सत्यापित शब्दावली नीति (Verified Vocabulary Only):**
   - प्राथमिक कक्षा में बच्चों को गलत शब्द सिखाने से रोकने के लिए केवल **सत्यापित संथाली शब्दावली** दिखाई जाती है।
   - यदि कोई अनुवाद उपलब्ध नहीं है, तो सिस्टम स्पष्ट रूप से प्रदर्शित करता है:  
     `"Verified translation unavailable"`
3. **वॉयस इनपुट (Voice Input):**
   - शिक्षक के लिए ब्राउज़र-आधारित हैंड्स-फ़्री हिंदी स्पीच रिकॉग्निशन।
4. **ऑडियो उच्चारण एवं फोनेटिक्स (Audio Playback):**
   - संथाली शब्दों का धीमा और सामान्य गति से स्पष्ट उच्चारण सुनने की सुविधा।
5. **चित्र फ्लैशकार्ड (Picture Flashcards):**
   - कक्षा निर्देश, गिनती (1 से 10), विद्यालय, पशु-पक्षी, प्रकृति और परिवार के 50 इंटरैक्टिव 3D फ्लिप कार्ड।
6. **संरचित पाठ (Learning Lessons):**
   - शिक्षक-छात्र संवाद और शिक्षक के लिए व्यावहारिक सुझाव (Teacher Tips)।
7. **इंटरैक्टिव कार्यपत्रिकाएँ (Interactive Worksheets):**
   - बच्चों के लिए मनोरंजक शब्द मिलान, क्विज़ और गिनती अभ्यास।
8. **ऑफलाइन मोड (PWA Offline Support):**
   - ग्रामीण क्षेत्रों के लिए डिज़ाइन किया गया: एक बार खोलने पर बिना इंटरनेट के भी पूरा सिस्टम काम करता है।

## 📁 प्रोजेक्ट संरचना (Project Files)

| फ़ाइल / फ़ोल्डर | विवरण |
| :--- | :--- |
| **`backend/main.py`** | FastAPI सर्वर, API एंडपॉइंट्स एवं स्टैटिक फ़ाइल होस्टिंग |
| **`backend/translator.py`** | सत्यापित संथाली अनुवाद इंजन (सख्त प्रमाणन जाँच) |
| **`backend/database.py`** | डेटाबेस लोडर एवं सर्च हेल्पर |
| **`backend/speech.py`** | ऑडियो और फोनेटिक उच्चारण सहायक |
| **`data/vocabulary.json`** | 50 सत्यापित संथाली शब्द व कक्षा निर्देश (ओल चिकी व उच्चारण सहित) |
| **`data/lessons.json`** | प्राथमिक कक्षा 1-2 के लिए 5 व्यावहारिक पाठ |
| **`data/worksheets.json`** | 4 इंटरैक्टिव कार्यपत्रिकाएँ (शब्द मिलान, क्विज़, संख्या पहचान) |
| **`frontend/index.html`** | आधुनिक, बाल-अनुकूल वेब डैशबोर्ड |
| **`frontend/style.css`** | आकर्षक रंग, टैबलेट एवं मोबाइल रिस्पॉन्सिव स्टाइलिंग |
| **`frontend/script.js`** | वॉयस इनपुट, अनुवाद, फ्लैशकार्ड, क्विज़ एवं ऑफलाइन फॉलबैक लॉजिक |
| **`frontend/manifest.json`** | प्रोग्रेसिव वेब ऐप (PWA) मेनिफेस्ट |
| **`frontend/service-worker.js`** | ऑफलाइन कैशिंग सर्विस वर्कर |

## 🚀 एप्लिकेशन कैसे शुरू करें (How to Run)

### 1. टर्मिनल (PowerShell / Command Prompt) खोलें
प्रोजेक्ट फ़ोल्डर `d:\SikshaSetu-AI` में जाएँ।

### 2. वर्चुअल एन्वायरनमेंट के साथ सर्वर शुरू करें
Windows PowerShell में यह कमांड चलाएँ:

```powershell
.\venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

## 🌐 ब्राउज़र में कैसे खोलें (How to Open in Browser)

सर्वर शुरू होने के बाद अपने ब्राउज़र (Google Chrome / Microsoft Edge / Firefox) में यह लिंक खोलें:

👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

### 💡 वैकल्पिक तरीका (Direct Frontend Offline Mode):
यदि आप सर्वर के बिना केवल इंटरफ़ेस देखना चाहते हैं, तो आप `frontend/index.html` फ़ाइल पर डबल-क्लिक करके भी सीधे किसी भी ब्राउज़र में खोल सकते हैं। सिस्टम में इन-बिल्ट ऑफलाइन फॉलबैक डेटा शामिल है!

## 📡 बैकएंड API एंडपॉइंट्स (Backend Endpoints)

- **`GET /api/health`** : सर्वर स्थिति एवं शब्दावली गणना।
- **`POST /api/translate`** : हिंदी वाक्य को सत्यापित संथाली (ओल चिकी) में अनुवादित करता है।
- **`GET /api/lessons`** : सभी संरचित पाठ प्राप्त करता है।
- **`GET /api/worksheets`** : इंटरैक्टिव कार्यपत्रिकाएँ प्राप्त करता है।
- **`GET /api/vocabulary`** : सत्यापित शब्दावली व फ्लैशकार्ड डेटा।
- **`GET /docs`** : स्वचालित इंटरैक्टिव Swagger API डॉक्यूमेंटेशन।
